# 키보드 수동 조종 패키지 설계

ROS 2 Humble 패키지 `drone_keyboard_control`을 `drone/drone_ws/src/`에 두고, Drone 컨테이너에서 두 노드를 별도 프로세스로 실행한다. 조작 규칙은 [확정된 요구사항](intent/keyboard-rc-control.md)을 따른다.

## 노드와 인터페이스

| 노드 | 입력 | 출력과 책임 |
| --- | --- | --- |
| `keyboard_teleop` | 조종 창의 키 누름·해제, 포커스 변경 | 키 상태를 기수 기준 이동 속도와 회전 속도로 변환해 발행한다. P를 누르는 순간 시동을 한 번 요청하고 결과를 표시한다. |
| `px4_offboard` | 조종 명령, 시동 요청, PX4의 비행 상태·로컬 위치·속도·방위각·명령 응답 | Offboard 진입과 시동을 관리하고, 좌표 변환과 정지 위치 유지를 수행한다. 이 노드가 PX4에 제어 명령을 보내는 유일한 주체다. |

두 노드는 다음 ROS 인터페이스로 연결한다. 이름은 상대 이름으로 두어 같은 네임스페이스에서 실행할 수 있게 한다.

| 인터페이스 | 타입 | 계약 |
| --- | --- | --- |
| `teleop/cmd_vel` 토픽 | `geometry_msgs/msg/TwistStamped` | `keyboard_teleop`이 키를 놓은 동안에도 20 Hz로 발행한다. `frame_id=base_footprint`는 기수를 따라 회전하는 수평 좌표계다. 선속도의 양의 축은 앞·왼쪽·위(m/s), 각속도 z의 양의 방향은 왼쪽(rad/s)이다. 최신 표본 하나만 유지한다. |
| `teleop/arm` 서비스 | `std_srvs/srv/Trigger` | 키보드 노드가 비동기로 호출한다. 오프보드 노드는 PX4에서 Offboard와 Armed를 모두 확인하면 성공을 반환한다. 거부·시간 초과 시 이유를 반환한다. 처리 중에도 제어 타이머와 PX4 구독은 계속 실행한다. |

## 조종 입력

조종 창은 W/S, A/D, Shift/Ctrl, Q/E의 누름과 해제를 각각 받는다. 반대 키는 해당 축에서 상쇄하고 OS의 키 자동 반복은 무시한다. 이동 벡터가 0이 아니면 길이를 2 m/s로 정규화한다. W+D와 W+Shift 모두 전체 목표 속력이 2 m/s다. Q/E는 이동과 독립적으로 각각 +π/4, −π/4 rad/s를 준다. 포커스를 잃으면 눌린 키를 모두 지우고 즉시 중립을 발행한다.

## 오프보드 제어

1. **준비와 시동.** 오프보드 노드의 독립 타이머(제안값 20 Hz)가 유효한 로컬 위치·방위각을 확인하고 `OffboardControlMode`를 1초 이상 미리 발행한다. P 요청이 들어오면 지상·중립 상태에서 `VehicleCommand`로 Offboard 전환과 Arm을 순서대로 요청한다. 각 단계는 PX4 상태로 확인한다. 시동 후 현재 지상 위치를 유지하며 새 Shift 입력부터 상승한다. [PX4 v1.16 Offboard](https://docs.px4.io/v1.16/en/flight_modes/offboard)
2. **이동.** 매 주기 실제 방위각으로 기수 기준 수평 속도를 PX4의 북·동 축으로 회전하고, 상승 속도는 부호를 바꿔 아래 방향 축에 넣는다. 따라서 W와 Q를 함께 누르면 기수가 돌아가는 동안 전진 방향도 바뀐다. 회전 중에는 지령 방위각을 회전 속도로 갱신하고, Q/E를 놓으면 그 시점의 방위각을 유지한다.
3. **감속과 유지.** 수평과 수직을 독립적으로 처리한다. 예를 들어 W+Shift에서 Shift만 놓으면 전진은 계속하고 수직 속도 목표는 0으로 둔다. 해당 방향 실측 속도가 정지 임계값 아래로 내려오면 그때의 추정 위치 또는 고도를 한 번 저장해 고정 목표로 사용한다. 정지 판정의 초기 제안값은 수평·수직 각각 0.1 m/s 이하가 0.2초 지속되는 경우다. 회전만 입력해도 수평 위치와 고도 유지는 계속한다.
4. **PX4 목표값.** `TrajectorySetpoint`에서 속도를 제어하는 축은 위치를 NaN으로 두고 속도를 지정한다. 유지 중인 축은 저장한 위치를 지정한다. 수평 두 축은 함께 전환한다. `OffboardControlMode`는 위치 유지 축이 있으면 위치 제어를, 모든 이동 축이 속도 제어이면 속도 제어를 선택한다. 사용하지 않는 가속도는 NaN으로 둔다. [PX4 v1.16 목표값 정의](https://docs.px4.io/v1.16/en/flight_modes/offboard#copter)
5. **입력 또는 연결 상실.** 마지막 입력 수신 후 0.25초가 지나면(초기 제안값) 오프보드 노드가 이동·회전 명령을 중립으로 바꾼다. 위치 추정과 Offboard 상태가 유효하면 감속 후 위치를 유지한다. PX4가 Offboard를 벗어나면 이전 이동 명령을 폐기하고 자동 재진입하지 않는다. 오프보드 노드 자체가 종료되면 PX4에 설정된 Offboard 연결 상실 동작이 적용된다. [PX4 연결 상실 동작](https://docs.px4.io/v1.16/en/flight_modes/offboard)

## SITL 인수 확인

| 조작 | 확인할 결과 |
| --- | --- |
| 지상에서 P, 이어서 Shift, 원하는 고도에서 Shift 해제 | P만으로 상승하지 않는다. Shift로 이륙하고 해제 후 감속해 고도를 유지한다. |
| W+D 및 W+Shift | 두 경우 모두 발행된 3차원 선속도 벡터의 길이가 2 m/s다. SITL에서 가속 후 실제 속력이 목표에 수렴한다. |
| W+E, 이어서 E만 해제 | 오른쪽으로 초당 45°의 목표 회전 속도로 돌며 전진한다. 해제 후 새 기수 방향을 유지하며 전진한다. |
| 비행 중 모든 키 해제, 별도 비행에서 조종 창 포커스 상실 또는 키보드 노드 종료 | 각 경우 감속한 뒤 정지 위치·고도·방향을 유지한다. 키보드 노드 종료 후에도 오프보드 타이머는 계속 동작한다. |
