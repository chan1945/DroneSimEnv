# 키보드 드론 수동 조종 패키지의 목표와 범위

## 목표

DroneSimEnv 사용자가 PX4·Gazebo 시뮬레이션에서 키보드를 RC 조종기처럼 사용해 드론을 직접 이륙시키고, 원하는 지점까지 비행한 뒤 공중에 정지시킨다.

## 조작 방식

| 키 | 동작 |
| --- | --- |
| P | 지상에서 시동을 건다(Arm). |
| W / S | 누르는 동안 기수 기준으로 전진 / 후진한다. |
| A / D | 누르는 동안 기수 기준으로 왼쪽 / 오른쪽으로 이동한다. |
| Q / E | 누르는 동안 왼쪽 / 오른쪽으로 초당 45° 회전한다. 놓으면 기수 방향을 유지한다. |
| Shift / Ctrl | 누르는 동안 상승 / 하강한다. 시동 후 지상에서 Shift를 누르면 이륙한다. 두 키를 모두 놓으면 고도를 유지한다. |

이동 입력이 있는 동안 수평·수직 성분을 합친 목표 속력은 2 m/s다. W+D로 수평 대각선 비행을 하거나 W+Shift로 전진하면서 상승할 때도 전체 목표 속력은 2 m/s다. 이동 키를 놓으면 해당 축의 속도 명령이 0 m/s로 돌아간다.

## 완료 기준

사용자가 P로 시동을 걸고 Shift로 이륙한다. 원하는 고도에서 Shift를 놓은 뒤, 이동과 회전을 조합해 원하는 지점으로 비행한다. 모든 키를 놓으면 드론이 감속해 멈추고, 멈춘 위치와 고도 및 기수 방향을 유지한다.

## 범위 밖

- 실기체 연동
- 자동 경로 비행
